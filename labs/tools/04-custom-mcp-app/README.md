# Lab 04 — Custom MCP server on Databricks Apps

**Category:** Unity AI Gateway for Tools · **Status:** 🟡 Planned

## Objective
Host your own MCP server as a **Databricks App**, governed and discoverable through the
Unity AI Gateway alongside managed servers.

## Databricks features
- Databricks Apps (hosting the custom MCP server).
- Unity AI Gateway MCP registration + access control.

## Outline
1. Implement an MCP server (e.g. FastAPI) exposing your tools.
2. Deploy it as a Databricks App.
3. Register it with the Gateway and set access controls.
4. Connect an MCP client and invoke the custom tools.
