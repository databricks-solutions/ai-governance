# Lab 03 — Function calling

**Category:** Unity AI Gateway for Tools · **Status:** 🟡 Planned

## Objective
Use **Unity Catalog functions** as governed tools with Foundation Model API tool calling, so
tool execution is permissioned and audited in UC.

## Databricks features
- Unity Catalog functions as tools.
- Foundation Model API tool/function calling on a governed endpoint.

## Outline
1. Author a Unity Catalog Python/SQL function.
2. Pass it as a tool in a chat completion request to the governed endpoint.
3. Execute the model-selected tool call and return the result.
4. Confirm permissions and audit logging in Unity Catalog.
