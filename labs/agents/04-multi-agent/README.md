# Lab 04 — Multi-agent / agent-to-agent

**Category:** Unity AI Gateway for Agents · **Status:** 🟡 Planned

## Objective
Compose multiple specialized agents that delegate to one another, with every model and tool
call routed through governed Gateway endpoints for consistent control and observability.

## Databricks features
- Multiple governed model + tool endpoints.
- Agent-to-agent delegation; shared usage tracking and guardrails.

## Outline
1. Build two or more specialist agents (e.g. retriever, analyst, writer).
2. Add an orchestrator that delegates across them.
3. Route all calls through governed endpoints / managed MCP tools.
4. Trace the full multi-agent run and review aggregate usage and cost.
