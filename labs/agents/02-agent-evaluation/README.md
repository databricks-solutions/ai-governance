# Lab 02 — Agent evaluation & monitoring

**Category:** Unity AI Gateway for Agents · **Status:** 🟡 Planned

## Objective
Evaluate and continuously monitor a governed agent with Mosaic AI **Agent Evaluation** and
MLflow, using the Gateway's payload/inference tables as the source of production traffic.

## Databricks features
- Mosaic AI Agent Evaluation, MLflow evaluation + tracing.
- Inference tables (Lab 03 / Models) and Lakehouse Monitoring.

## Outline
1. Assemble an evaluation set (curated + sampled from inference tables).
2. Run Agent Evaluation for quality, safety, and cost metrics.
3. Schedule monitoring over live governed traffic.
4. Alert on regressions and feed results back into guardrail/limit tuning.
